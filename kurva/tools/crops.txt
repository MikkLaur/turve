# Kurva Nokitseb: per-photo settings for tools/pipeline.py and tools/images.sh
#
# One line per page id: <id> key=value ... (no spaces inside values). Order of the lines = order on the page.
# All coordinates are in pixels of the image at that stage.
#
#   role=     B before, D during, P process (warm monochrome) | A after, K Kristo (colour)
#   src=      source file, relative to previous-kurva-work/ (or KURVA_SRC)
#   rot=      90|180|270: rotate the pixels clockwise before anything else
#   cut=      x,y,w,h: frame cut out of a collage (inside the seams, with a 4 px safety margin), after rot
#   straighten=auto|none|manual:theta,v,h   (default auto: fit rotation + vertical keystone to long verticals)
#   vmax=     limit of the keystone (1/image height) so top-down wide-angle shots are not stretched oddly
#   horiz=1   also fit near-horizontal lines to level (worktops, horizons) - only where they should be level
#   ignore=   x0,y0,x1,y1 (fractions): ignore verticals whose centre is in this box
#   focus=    fx,fy: where (fractions of the warped canvas) the 3:4 crop is centred; default 0.5,0.5
#   fit=      <1: a tighter crop than the biggest 3:4 box, same centre
#   box=      x,y,w: explicit 3:4 crop box in the warped canvas (overrides focus/fit)
#   clone=    dx,dy,w,h<sx,sy;...  clone-stamp (cropped-image pixels, before upscale)
#   inpaint=  x,y,w,h;...          small inpaint fill (cropped-image pixels, before upscale)
#   up=2      Real-ESRGAN 2x (collage frames, Kristo, anything needed larger than its source)
#   wb=none   keep the white balance as shot (LED-lit scenes); lift= lc= vib= exp= warm=: colour recipe tweaks
#   alias=    this id is the same picture as another id (files are copied, not processed again)
#   note=     free text for photos.md (use _ for spaces)
